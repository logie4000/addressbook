# Address Book API

A Rails JSON API (`/api/v1/people`, `/api/v1/addresses`) that stores its data
in Amazon DynamoDB through the [Dynamoid](https://github.com/Dynamoid/dynamoid) gem.

## Data model

Two DynamoDB tables, both billed on demand (pay per request):

| Table (prefix + name) | Key  | Secondary indexes                      |
|-----------------------|------|----------------------------------------|
| `<prefix>_people`     | `id` | `parent_id-index`, `address_id-index`  |
| `<prefix>_addresses`  | `id` | none                                   |

Ids are UUID strings generated by Dynamoid. Relationships are stored as id
fields (`address_id`, `spouse_id`, `parent_id`, `addressee_id`), and the two
indexes let the API find a person's children and an address's residents
without reading the whole table.

## Configuration

| Variable                | Purpose                                                        |
|-------------------------|----------------------------------------------------------------|
| `DYNAMODB_ENDPOINT`     | DynamoDB Local URL, e.g. `http://localhost:8000`. Unset on AWS. |
| `DYNAMODB_TABLE_PREFIX` | Table name prefix. Default `addressbook_<RAILS_ENV>`.          |
| `AWS_REGION`            | AWS region. Default `us-east-1`; set automatically in Lambda.  |

## Running locally

Start DynamoDB Local, create the tables, and run the server:

```sh
docker run -d -p 8000:8000 amazon/dynamodb-local:2.6.1
export DYNAMODB_ENDPOINT=http://localhost:8000
bin/rails dynamodb:create_tables
bin/rails server
```

Or run the whole stack with `docker compose up` from the repository root.

## Tests

The tests need DynamoDB Local on port 8000 (or `DYNAMODB_ENDPOINT` set):

```sh
docker run -d -p 8000:8000 amazon/dynamodb-local:2.6.1
bin/rails test
```

## Deploying to AWS

In production the API runs in AWS Lambda (via the [Lamby](https://lamby.cloud)
gem and `Dockerfile.lambda`), deployed with AWS SAM from the repository root.
See [docs/deploy-aws.md](../docs/deploy-aws.md).
